# Live Demonstration Script (about 6–7 minutes)

Before you start: open `index.html` in a browser, click **Reset my progress** on the home page, and have a phone-size window ready (browser dev tools, F12 then device toolbar).

| Time | Presenter action | What to say |
|---|---|---|
| 0:00 | Home page | "This is FluentSpring. It teaches skimming and scanning for university students. The path below shows the six required stages." |
| 0:30 | Click **Start Learning**; show objectives; tick one box | "Objectives link to CLO1. Learners self-check their confidence." |
| 1:00 | Warm-up: answer wrongly on purpose, then check | "Learners get immediate feedback with an explanation. We use rule-based checking, not AI." |
| 1:45 | Techniques: press *Title*, *First sentences*, *Conclusion* in the skimming demo; then *Dates* in the scanning demo | "The learner sees which parts a skimmer reads and what a scanner looks for." |
| 2:30 | Complete the quick check | "Learners must apply the concept immediately." |
| 3:00 | Guided practice: open a hint in step 4; type the name | "Hints and explanations support learners. Progress counts steps checked." |
| 4:00 | Main activity: answer Activity A; scan for 14 March in Activity B; try `7 March` | "The date 7 March is a distractor. The explanation teaches the habit of reading around the answer." |
| 5:00 | Assessment: submit with one blank question; then complete and submit | "It blocks incomplete submissions. After submitting, learners see score, percentage and explanations." |
| 5:45 | Feedback page: filter *Only incorrect*; do the revision exercise; write a reflection; click **Download my learning record** | "Learners see areas to improve, apply them to a new passage, and reflect. The record can go to the teacher." |
| 6:30 | Mobile view | "The design is responsive: the menu collapses and the passage stacks above the questions." |

Backup plan: if the browser blocks LocalStorage, the lessons still work; only saved progress and the feedback page's personal result will be empty.
