# FluentSpring – Skimming and Scanning (Group C10)

Frontend-only learning website (HTML5, CSS3, vanilla JavaScript). No installation needed.

## Run
Double-click `index.html`, or use the VS Code **Live Server** extension.

## Structure
```
index.html  objectives.html  warmup.html  techniques.html
guided-practice.html  main-activity.html  assessment.html  feedback.html
css/style.css
js/main.js            shared header/footer, LocalStorage, question engine
js/warmup.js          Stage 1
js/techniques.js      Stage 2 (added: demos and quick check)
js/practice.js        Stage 3
js/main-activity.js   Stage 4 (added: separate from practice.js)
js/assessment.js      Stage 5
js/feedback.js        Stage 6
assets/images/logo.svg
docs/                 lesson plan, presentation, scripts, AI log, evidence log, test checklist
```

## Six stages -> pages
1 Warm-up -> warmup.html | 2 Delivery/modelling -> techniques.html | 3 Guided practice -> guided-practice.html |
4 Main task -> main-activity.html | 5 Review and assessment -> assessment.html | 6 Feedback and revision -> feedback.html

## Notes
- Progress, scores and reflection are saved in the browser's LocalStorage (this device only). "Reset my progress" on the home page clears them.
- All answers are checked by pre-written JavaScript rules. No AI evaluates learners.
- All universities, people and events in passages are fictional and labelled as such.
